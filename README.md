# FAZAL.OS — Portfolio

A static, 3D-inspired personal portfolio for Mohammed Fazal Shaikh.

## Included
- Futuristic Three.js hero backdrop
- Personal portrait + HUD treatment
- Project universe with editable project cards
- Interactive terminal (`Ctrl/Cmd + K`)
- Skills/system architecture board
- Experience and leadership timeline
- Awards / proof section
- Resume PDF viewer + download
- Email, LinkedIn, GitHub and phone contact links
- Responsive mobile layout

## Run locally
Because the 3D module uses a CDN, serve the folder over HTTP instead of opening `index.html` directly.

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages (recommended free deployment)
Create a public repository named:

`Fazal7867.github.io`

Then upload the contents of this folder to the repository and enable GitHub Pages from the repository settings. The expected address is:

`https://Fazal7867.github.io`
